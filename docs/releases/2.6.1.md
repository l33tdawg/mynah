# Mynah 2.6.1

The bundled SAGE brain moves to **11.19.21**, and the Even G2 companion reaches
**0.2.8 beta**: two controls that acted on a single tap now ask first, and a
refused microphone no longer answers with an internal error code.

## The brain, 11.18.27 → 11.19.21

Twenty-three SAGE releases landed while the pin sat still. All of their notes
were read against Mynah's tool allowlist before the pin moved, and three things
in them touch a tool this appliance offers:

- `sage_get_links` is new (typed links can now be read, not only written). It is
  **not** offered to the model in this release: the on-device tool ceiling is a
  measurement, and that measurement is its own piece of work.
- `sage_directory` searches local and federated agents by default. Safe here and
  verified: remote agents appear only when both peers are new enough, root
  identities stay excluded, and explicit blocks still apply.
- 11.19.21 closes a tombstone bypass and lets the node own the duplicate rule.
Mynah never decided duplicates, so this is the node getting stricter under an
unchanged caller.

Nothing was removed or renamed, so no exclusion in the allowlist expired.

## Even G2 companion 0.2.8 beta

- **Forget pairing asks first.** It used to clear the saved link on the first
  touch, on a screen with no undo; the control now waits for a second tap and
  says so while it waits. Unpair on the Mac asks in the same way.
- **A refusal is reported in words, not in Even's internal wording.** Every call
  into the glasses bridge — microphone, page containers, storage, location — is
  treated as refusable. A tap to talk now reports a microphone the Even app
  refused, a full queue, or a Mac that needs restarting to catch up, instead of
  showing a code where a sentence belongs.

Companion 0.2.1 remains in review at Even Hub. 0.2.8 is attached here as a
developer/beta build.

## Validation

2,560 Mac tests executed with zero failures (17 additional tests skipped), with
the live-node tests switched on: they run against the SAGE installed on the
build machine, which is 11.19.21 — the same node this release vendors, so they
exercise this brain rather than a fixture that agrees with whatever the code
expects. 47 companion tests passed. The Mac app is Developer ID signed, Apple
notarized and stapled.

Download the DMG for Mac installation. The companion package is attached to this
release for developer installation.
