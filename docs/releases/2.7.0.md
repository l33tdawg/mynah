# Mynah 2.7.0

Mynah can run work on a clock you set, whether or not you are talking to it.

## The conversation this came from

Asked whether it could check its inbox "from time to time", Mynah answered
honestly:

> I have no timer or scheduler on my end. I only run when you speak to me, so a
> poll would need something outside me to wake me up on a clock, and I have no
> tool that does that.

Every word of that was true. Two things did already run on a clock, and neither
is this one: the proactive check, which looks on your own interval at the same
two questions, and the reminder ladder, which reads dates out of your task list.
Neither is "do this thing, at this time, and tell me".

So there is a third thing now, and it is yours to set.

## What you send

    //schedule every day at 8am: check my inbox and tell me what's waiting
    //schedule every Monday at 9:30am: send me the week ahead
    //schedule every 30 minutes: check whether anything is waiting

    //schedules                what is set up, numbered
    //schedule cancel 2         stop one
    //schedule pause 2          hold it for a while; resume 2 starts it again

At the appointed minute Mynah runs that sentence through the ordinary brain — the
whole tool catalogue, the turn ceiling, documents, the thread's memory — and
messages you the answer. `//help` lists it alongside the rest.

## What it will not do

**It will not guess at a time.** "every day at 8" is refused rather than read as
morning or evening, and the reply says which one to add. A cadence read wrongly
is not a wrong sentence: it is your phone buzzing at the wrong hour for as long
as the request stands.

**It will not nag about a Mac that was asleep.** A laptop shut through eight in
the morning has not missed eight, it has woken up — so the work runs once when it
wakes, late and once, never once per morning it slept through. A schedule set up
at nine for eight o'clock starts tomorrow.

**It will not speak first about anything else.** Standing work is not news you
did not ask for at an hour you did not choose, so neither the proactive switch
nor the quiet hours suppress it — you chose the time. Pause does: nothing is
claimed while Mynah is stopped, and whatever came round meanwhile runs once when
you switch it back on.

**It will not set one up for you.** Asked for this in conversation, Mynah tells
you the command rather than pretending. The local model's tool catalogue is at
the size it was measured at, and a cadence a model misreads here is not a wrong
answer — it is a stranger messaging you every morning for a year. The sentence
that creates one is yours, and it is read by code rather than by the model.

## On the Mac

What is set up rides every turn on every surface, so "what have you got
scheduled?" is answered from the list instead of denied. The list is a file —
`~/Library/Application Support/SAGE Voice Bridge/scheduled-work.json` — and there
is no screen for it yet.

## Validation

2,618 Mac tests executed with zero failures (17 skipped), including the four
live-node tests against the SAGE on this Mac. The Mac app is Developer ID signed,
Apple notarized and stapled, and the disk image verifies: checksum, signature,
Gatekeeper, and a stapled ticket.

The bundled SAGE version remains **11.19.22**, unchanged from 2.6.3. A newer SAGE
release (11.23.7) exists and is deliberately **not** in this build: the pin is
bumped in its own change, with that release's notes read against Mynah's tool
allowlist first, because a SAGE release is what makes those exclusions go stale.
The Even G2 companion is unchanged at 0.2.9.
