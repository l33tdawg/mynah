# Mynah 2.6.0

Mynah can look at the pictures you send it. Send a photo on Signal or WhatsApp
and ask about it — what's in it, what it says, whether the plant needs water —
and the answer comes from a model that actually looked.

## What works now

- **Pictures reach every brain that can read one.** Anthropic, OpenAI, DeepSeek,
  Kimi and Gemini are sent the image in the shape each of them asks for. The
  image is downscaled and re-encoded to a 1024 px JPEG first, so a 12 MP phone
  photo costs about 100 KB rather than several megabytes of vision tokens.
- **Local brains see too, with nothing leaving the Mac.** The model Mynah
  installs for "fully on this Mac" — `qwen3.5:4b` — is itself multimodal, so
  photos are read on your own machine by the same brain that answers. Privacy
  preserving was already the default; now it can also see.
- **Which models can see is a per-model fact, and the picker says so.** DeepSeek
  is the case that makes it concrete: its Quick model reads pictures and its
  Careful model does not, and the Careful row now says "Can't read pictures —
  Quick can." rather than letting you find out by sending one.
- **The Privacy screen has a row for it.** A picture is read on this Mac when
  your brain runs here, and goes to the model when it is a cloud one that can
  read pictures. A model that cannot read pictures is never sent an image; the
  picture is kept here.

## Model refresh

Every provider's catalogue was re-read on 13 September 2026 rather than trusted
from the last sweep, and three picks moved:

- **DeepSeek** is `deepseek-flash` / `deepseek-v4-pro`. The name Mynah used to
  ask for, `deepseek-v4-flash`, was retired by the vendor; it is still accepted
  and still served by the current model, so a Mac already set up on it keeps
  working — and keeps its vision — without being asked to change anything.
- **Gemini** Quick is `gemini-3.8-flash`, the current stable Flash model.
- **OpenAI** Careful is `gpt-6-astra`, the vendor's most capable model. Both
  OpenAI rows take images.

`docs/MODEL-CHOICES.md` carries the reasoning, the prices and a new "Reads
pictures" column.

## Also

- A text-only local model is no longer told it can see. Its photo is kept and
  not looked at, which is what actually happens, instead of the model being
  handed a caption and answering that no image arrived.
- First-run setup already installs everything for you — Ollama, the local model,
  and the model that gives it memory — and verifies them by serving a real
  request before the screen moves on. That path was re-checked for this release
  rather than assumed, including the case where Ollama is absent entirely.

## Validation
